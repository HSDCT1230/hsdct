# 可选：拆成独立仓库

1.0 的正式位置是本仓库的 `ao3-hongdeng-wuhai/`。只有想单独收藏时才需要新仓库。

1. 在 GitHub 新建空的公开仓库，不要勾选添加 README。
2. 把本目录里的文件放到新仓库根目录（不要多套一层 `ao3-hongdeng-wuhai/`）。
3. 把 `ushuaia-fin-del-mundo.css` 里的背景图地址改成新仓库的 raw 链接，例如：

`https://raw.githubusercontent.com/HSDCT1230/ao3-hongdeng-wuhai/main/assets/les-eclaireurs-bg.jpg`

4. 提交并推送到 `main`。
